## `> whoami`

Software Developer at **Applied Contexts** in Raleigh, NC. I build ML-powered platforms, LLM orchestration pipelines, and distributed microservices. MS Computer Science from NC State, two IEEE publications, and prior experience at HPE and CSIR research labs. I'm mostly wiring up production AI workflows — Claude API, LangChain, MCP servers, and a lot of event-driven plumbing.

Currently open to SDE, ML Engineering, and Platform Engineering opportunities.

- Full-stack with TypeScript, Node.js, Vue.js/Nuxt 3, PostgreSQL, FastAPI, Flask, React, and MongoDB
- Cloud and DevOps across AWS (EC2, S3, Lambda, OpenSearch), GCP, Docker, Kubernetes, Helm, and GitHub Actions CI/CD

- Monitoring and data viz with Datadog, Prometheus, Grafana, Power BI, and Tableau
